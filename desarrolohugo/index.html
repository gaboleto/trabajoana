Sobre Hugo

Hugo es un **generador de sitios web estaticos ** escritos en Go. Es rápido , flexible y permite crear sitios con Markdown de manera sencilla.

Características principales

  • Muy rapido al generar sitios
  • Compatible con Md y Html
  • Permite usar temas predefinidos
  • Genera sitios listos para producción
